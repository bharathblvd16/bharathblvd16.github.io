# Bharath Portfolio

A simple personal portfolio site for Balivada Bharath.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize

- Update links/contact details in `index.html`.
- Update project descriptions in `index.html` and `script.js`.
- Change colors/fonts in `style.css`.

No framework or build step is required.
